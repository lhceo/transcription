## [v1.2] - 2026-05-23

**UX 全面改善**: alert()/confirm() のカスタム UI 置き換え、履歴行の情報整理、編集モードの視覚フィードバック強化、文字起こし完了通知など。

### 追加
- **トースト通知** (`window.showToast`): 削除成功・エラーなどをページ内通知で表示
- **カスタム確認モーダル** (`window.showConfirm`): ブラウザ標準の `alert()`/`confirm()` を廃止し全画面オーバーレイダイアログへ統一
- **文字起こし完了通知**: 処理完了時にトースト（8秒）+ タブタイトルバッジ + Web Notification（許可時）で通知
- **通知許可ボタン**: アップロードフォーム横に「🔔 完了時に通知」ボタンを追加（`Notification.permission === 'default'` の場合のみ表示）
- **詳細画面 toolbar の編集モード強化**: 編集中はツールバーに青枠 + 薄青背景でモードを明示

### 変更
- **履歴行の情報整理**:
  - ファイル名を 15px でやや強調
  - ファイルサイズ・精度ラベル（Best/Nano）を削除
  - 区切り文字を `·` に統一（所要時間 · 日付 · コスト）
  - コストをミュートカラー（緑Bold → グレー）に変更
- **音声削除ボタン再配置**: プレイヤーコントロール行から切り離し、専用フッター行（右寄せ）へ移動
- **品質モード選択のコピー改善**:
  - ラベル: 「文字起こしの精度」→「品質モード」
  - 選択肢: 「高精度 (Best)」→「高精度（推奨）」、「コスト重視 (Nano)」→「標準」
  - 価格表示: 「1時間あたり約 55円」→「約 55円 / 時間」
- **コストアイコン**: `$` 形から `¥` 形 SVG に変更
- **ページタイトル区切り**: 全ページで `-` → `|` に統一（`ホーム | 音声文字起こし` など）
- **ドロップゾーンヒント**: `mp3／mp4／...` の全角スラッシュ → `mp3 — mp4 — ...` に変更
- **ヘルプページの品質モード説明**: 新しい選択肢名に合わせて更新

## [v0.1-mac-app-snapshot] - 2026-05-12

社内未配布のまま、Web アプリへ全面書き換えする前の Mac アプリ最終スナップショット。

### Mac アプリ版の機能（このスナップショットに含まれるもの）
- Tkinter (customtkinter) ベースのデスクトップ UI
- mlx-whisper による日本語文字起こし
- pyannote-audio による話者分離
- 編集機能（テキスト編集・話者リネーム）
- エクスポート（TXT / SRT / JSON）
- プロジェクト保存・読込
- Undo / Redo
- macOS Keychain による HuggingFace Token 保存
- py2app による .app パッケージ化

### このスナップショットを残す理由
- 過去の状態に戻して動作検証できるようにする
- 「Web アプリ版」との比較対象として保全
- 万一 Web アプリ化が頓挫した場合のフォールバック

### このスナップショットの既知の問題（書き換えの動機）
- 2時間音声で 16GB Mac が OOM クラッシュ
- pyannote の MPS / CPU 切替で速度と安定性のトレードオフが解決できない
- 配布先 Mac のスペック差を吸収できない
- 外出先での使用に向かない設計
- 全 2,191 行が `app.py` に集約されており、保守性に課題
